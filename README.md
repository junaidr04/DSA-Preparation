# DSA Preparation

A structured, self-paced journey through Data Structures & Algorithms, built for technical interview readiness at top-tier tech companies.

## 📌 Overview

This repository documents my complete solve history through **NeetCode 150**, preceded by a foundational **Core 34** problem set, all implemented in **C++**. The goal is deep pattern mastery — not just problem completion — reinforced through a spaced repetition review cycle.

## 🔁 Retention Strategy

Solving a problem once isn't the goal — retaining the pattern is. Every problem is revisited on a **1-4-7-21 day spaced repetition schedule** to ensure long-term recall under interview pressure, rather than short-term memorization.

## 🛠️ Language & Tools

- **Language:** C++
- **Practice Source:** NeetCode 150 + curated FAANG interview problem sets
- **Method:** Independent solve attempt first (45-minute time-box) → hint-based debugging if stuck → clean solution → spaced repetition review
